1.About
This is a simple Weather Dashboard created for the She Builds task. It allows users to search for a city and check its current weather.

2. Features
* Search weather by city
* Show current temperature
* Show weather condition
* Show error for invalid city

3.Technologies Used
* HTML
* CSS
* JavaScript
* Weather API

4. How It Works

User enters city
       ↓
JavaScript sends API request
       ↓
Weather API returns data
       ↓
JavaScript processes the response
       ↓
Weather information displayed on webpage
